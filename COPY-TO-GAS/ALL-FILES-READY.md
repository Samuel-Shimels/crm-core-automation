## 🆘 Troubleshooting

### Charts not showing?
- ✅ Verify Chart.js CDN loaded (check Part-1-Head-CSS.txt line 12)
- ✅ Check browser console for errors
- ✅ Verify canvas IDs match (revenueChart, dealDistChart, etc.)

### Theme toggle not working?
- ✅ Verify theme-toggle button copied (Part-3-Sidebar-Nav.txt)
- ✅ Verify toggleTheme() function copied (Part-8-JavaScript.txt)
- ✅ Check data-theme attribute on `<html>` tag

### Email won't send?
- ✅ Verify Gmail OAuth scope in appsscript.json
- ✅ Authorize Gmail permissions
- ✅ Check Part-9-Code-Complete.txt has sendEmailApi()

### Icons showing as squares?
- ✅ Verify Bootstrap Icons CDN loaded (Part-1-Head-CSS.txt line 10)
- ✅ Clear browser cache
- ✅ Check icon class names (bi bi-icon-name)

### Alerts not showing?
- ✅ Verify custom alert CSS copied (Part-1-Head-CSS.txt)
- ✅ Verify showAlert() function copied (Part-8-JavaScript.txt)
- ✅ Check console for JavaScript errors
